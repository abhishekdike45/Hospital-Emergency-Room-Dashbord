🏥 Hospital Emergency Room Dashboard

📌 Project Overview

The Hospital Emergency Room Dashboard is an interactive dashboard developed using Microsoft Excel to analyze hospital emergency room data. It provides useful insights into patient admissions, waiting time, satisfaction scores, gender distribution, and age-group analysis.

🎯 Project Objectives
Analyze the total number of patients visiting the emergency room.
Monitor average patient waiting time.
Understand patient admission and non-admission rates.
Analyze patient distribution by gender.
Visualize patient data across different age groups.
Compare monthly and yearly hospital performance.

📊 Dashboard Features
Total Patients: Displays the total number of patients.
Patient Wait Time: Shows the average patient waiting time.
Patient Satisfaction: Displays the patient satisfaction score.
Admission Status: Compares admitted and non-admitted patients.
Gender Analysis: Visualizes the distribution of male and female patients.
Age Group Analysis: Displays patient counts across different age groups.
Monthly Filter: Allows users to explore data by month.
Year Filter: Supports year-wise data comparison, where available.
